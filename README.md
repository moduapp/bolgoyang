# 볼고양 🐈‍⬛✨

> 사주, 같이 볼고양?

귀여운 고양이 캐릭터와 함께 나의 사주와 오늘의 흐름을 쉽고 다정하게 살펴보는 웹 서비스입니다.

## 주요 화면

- 볼고양 브랜드 랜딩 페이지
- 성별·생년월일·양력/음력·태어난 시간 입력
- 운명 고양이 결과 미리보기
- 기본 사주·궁합·일과 재물운 콘텐츠
- 데스크톱과 모바일 반응형 디자인

## 시작하기

```bash
npm install
npm run dev
```

Node.js 22.13 이상을 권장합니다.

## 주요 파일

- `app/page.tsx`: 페이지 콘텐츠와 입력 인터랙션
- `app/globals.css`: 전체 디자인 및 반응형 스타일
- `public/bolgoyang-hero.webp`: 메인 일러스트
- `public/bolgoyang-story.webp`: 브랜드 소개 일러스트

## 안내

현재 사주 결과는 서비스 흐름을 확인하기 위한 예시입니다. 실제 서비스에서는 만세력 계산 또는 사주 풀이 API 연결이 필요합니다.
